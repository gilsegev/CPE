# CPE Learning and Certification

This context describes the language used to decide when an individual educator completes Guiding Diversity learning and earns CPE credit.

## Language

**Course**:
A purchased learning experience composed of one or more ordered modules.
_Avoid_: Class, program

**Module**:
An ordered unit of course content with its own CPE value and an optional module quiz.
_Avoid_: Chapter, video module

**Module Quiz**:
A configurable knowledge check attached to the end of one module.
_Avoid_: Quiz module, course quiz

**Module Completion**:
The learner's durable satisfaction of a module's content requirement and, when present, its quiz requirement.
_Avoid_: Chapter completion, progress boolean

**Course Completion**:
The one-time record that every module requirement in a purchased course has been satisfied by a learner.
_Avoid_: 100% progress, approved submission

**CPE Value**:
The whole-number continuing-professional-education credit assigned to a module.
_Avoid_: Module hours when the value is credit rather than elapsed time

**CPE Award**:
The immutable whole-number sum of module CPE values earned and recorded when a learner completes a course.
_Avoid_: Current course total

**Certificate**:
The fulfillment record and generated document that attest to one course completion and its CPE award.
_Avoid_: Completion

**Feedback Response**:
An optional, identified post-course evaluation submitted after course completion and independent of certificate eligibility.
_Avoid_: Completion survey result, observability event
